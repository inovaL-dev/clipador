# Segurança

## Como avisar sobre uma falha

Não abra uma issue pública. Use **Security > Report a vulnerability** neste repositório e descreva o problema e como reproduzi-lo.

## Versões atendidas

As correções saem na versão mais recente.

## Seus dados

As credenciais do YouTube ficam na pasta `dados` do seu computador. Nunca compartilhe essa pasta nem os arquivos `youtube_cliente.json` e `youtube_token.json`.
